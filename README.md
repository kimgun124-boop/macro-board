# 🌍 매크로 시황 보드

숫자는 사실로, 판단·AI 해설은 해석으로 나눠 보여 주는 매크로 대시보드예요. 색은 한국식(상승 빨강, 하락 파랑).

## 화면

- **🎯 비중 판단(첫 화면)**: 신호 12개(추세 35 · 금리·유가 25 · 위험 20 · 수급·폭 20점)를 더해 100점 점수 → 주식 비중 구간(공격 80~100% · 확대 60~80% · 중립 40~60% · 축소 20~40% · 방어 0~20%). 레드라인(10년물 5% 이상이면 축소 위로 못 감, 나스닥 -3%·전닉 동반 하락이면 중립 위로 못 감), 한국:미국 나누기, 비중이 바뀌는 조건, 강한/약한 섹터·종목, 과거 점수 흐름과 구간별 그 뒤 20일 성과. 점수표는 `alloc.py` 숫자만 고치면 돼요.
- **🌐 세계 시황 해석**: 매일 오전 8시·밤 8시 Claude가 쓰는 짧은 표 위주 해석 글(`reports/`) + 유가·중동 + 세계 지수
- **차트 보드**: 세계 지수·미국 섹터 ETF·테마 ETF·대장주 미니 캔들 차트(20·50·200일선) + 추세 단계 + 크게 보기(캔들·이평·거래량)
- **이슈 ↔ 섹터**: 뉴스로 이슈(유가·금리·AI·관세·전력·방산·바이오·한국·신용 등)를 찾고, 관련 섹터가 가설대로 움직였는지 5일 등락으로 확인
- **경제지표**: CPI·근원 CPI·근원 PCE·고용·실업률 등 FRED 12개 + 발표일 각국 지수(미국·유럽·한국·일본·대만)·금리·달러 반응표 + 지표별 AI 해석(기사·리포트 검색)
- **지수·금리·위험**: 세계 주요 지수 14개, 미국 금리(2·5·10·30년), 환율, 원자재, VIX·MOVE·OVX, 하이일드·BBB 스프레드, 기대인플레, 실질금리, 장단기 금리차, 시장 폭(RSP − SPY)
- **섹터·대장주**: 미국 섹터 ETF 12개, 섹터별 대장주(섹터 대비 강약), 테마 ETF, 한국 대장주
- **사실 필터 뉴스**: 지난 24시간 뉴스를 사건별로 묶고 라벨을 붙여요

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py              # 실제 데이터
MACRO_MOCK=1 streamlit run app.py # 인터넷 없이 가짜 데이터로 화면만
MACRO_MOCK=1 pytest -q            # 테스트
```

**Streamlit Cloud**: share.streamlit.io → Create app → 저장소 `kimgun124-boop/macro-board`, 브랜치 `main`, 파일 `app.py`.

**AI 해설 켜기**: Streamlit 앱 → Settings → Secrets 에 `ANTHROPIC_API_KEY = "sk-ant-..."` 한 줄. (선택) `FRED_API_KEY = "..."` 를 넣으면 경제지표 발표일이 추정이 아니라 정확한 날짜가 돼요(fred.stlouisfed.org에서 무료 발급).

**디스코드 브리핑**: 저장소 Settings → Secrets and variables → Actions → `DISCORD_WEBHOOK_URL` 추가. Actions 탭에서 "매크로 아침 브리핑" → Run workflow로 바로 시험할 수 있어요.
